HomeLedger 家计本 — 陈家四口 2026 年 9–11 月的家庭预算本：收支总览、记账、预算、账单、储蓄目标与月度报表，全部数字由 186 笔支出、12 笔收入的真实记账算出，每一个控件都能用。9 月和 10 月也是逐笔真实记账，报表是三个月的真对比，不是估算数。

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `app/index.html` directly in a browser. No build step, no network requests: the site is plain static files under `app/`.
